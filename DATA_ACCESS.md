# Data access

Primary sequence data are not redistributed in this code repository.

| Resource | Accession | Access | Use |
| --- | --- | --- | --- |
| Study sequencing data | GSE310360 | NCBI GEO; pending public release | Fiber-seq, DAF-seq, ChIP-seq, and processed study files |
| Study sequencing project | PRJNA1346452 | NCBI BioProject; pending public release | Primary sequencing records |
| SMaHT Benchmarking | phs004193 | Controlled, dbGaP | Somatic and testis comparison data |
| SMaHT Production | phs004104 | Controlled, dbGaP | Comparison data |
| CenSat annotations | `hloucks/CenSatData` | Public, GitHub | HG002 centromere, satellite, CDR, and rDNA definitions |
| Motif catalog | JASPAR 2024 CORE vertebrates | Public, JASPAR | Transcription-factor position-weight matrices |

The study records will be released publicly with the article; peer-review
access is supplied through the manuscript submission. Controlled-access
records must be obtained independently under their data-use terms. The default
repository commands use only the compact processed tables under `data/source/`.
