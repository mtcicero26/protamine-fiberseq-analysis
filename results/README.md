# Reference outputs

This directory contains the PNG previews and editable-text PDFs generated by:

```bash
python -m analysis.reproduce
```

The testis-transition workflow also writes
`testis_transition/transition_trajectory.tsv`, the 20-bin median and
interquartile-range summary used for its trajectory plot.

`assay_controls/` contains the Hia5 dose/time titration composite and the
paired technical-replicate footprint/lacuna distribution composite.

`read_heatmaps/` contains seven composites reconstructed from the bundled
deidentified footprint intervals: four TSS-centered Fiber-seq panels, paired
mouse and low-motility Fiber-seq panels, and four representative paired-donor
DAF-seq loci.
